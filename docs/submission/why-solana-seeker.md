# Why Solana / Seeker

## Solana

- **Programmable settlement** — Anchor enforces vault collateral, caps, observation hashes, and claim/refund rules without a claims desk.
- **Fast, cheap Devnet UX** — phone-friendly confirmations for quote → approve → position.
- **Transparent proof** — every purchase and settlement is an Explorer-verifiable transaction.
- **SPL collateral** — SKYT (Devnet test mint) today; path to real collateral later without inventing weather values off-chain.

## Solana Seeker (mobile-native)

- SkyHedge is a **native React Native Android** app, not a WebView wrapper — built for the Seeker form factor and outdoor operators who check risk away from a desk.
- **Mobile Wallet Adapter + Phantom** keeps signing on-device; SkyHedge never holds user keys.
- Companion web at https://skyhedge.app for waitlist and Devnet product UI at `/app`.
