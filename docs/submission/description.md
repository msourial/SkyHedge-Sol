# SkyHedge — Encode description (≤150 words)

SkyHedge is parametric weather protection on Solana Mobile. The site opens with “Rain on your plans? Get paid.” Open web app goes to the Devnet companion. On the Seeker, Markets leads with New York when a rainfall window is selling. Protect is an expiry chain: pick Nov 1 · W, the one priced trigger, and 100 SKYT, then approve one unsigned open_position in Phantom. The premium sits in that market’s vault. After expiry, settlement uses NOAA’s final Central Park data. Hit the trigger and the payout can be claimed. If valid data never arrives by the deadline, the market is marked DataUnavailable and the premium comes back. SkyHedge does not invent a rainfall total. Collateral is SKYT, a valueless Devnet test token. The native app is React Native for Solana Seeker. The site is skyhedge.app.
