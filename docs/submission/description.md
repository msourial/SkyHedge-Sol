# SkyHedge — Encode description (≤150 words)

SkyHedge is parametric weather protection on Solana Mobile. Pick a place and a rainfall risk, see a quote priced from NOAA history and forecast, approve the purchase in Phantom via Mobile Wallet Adapter, and hold an on-chain position in a fully collateralized per-city vault. When the observation window closes, a hashed NOAA package settles the market: hit the trigger and claim the fixed payout; if valid data never arrives by the deadline, reclaim the premium. Built as a native React Native Android app for the Solana Seeker, with a Storm Glass web companion at skyhedge.app. Collateral is the valueless Devnet test token SKYT. No claims adjusters, no invented weather values — public data and an Anchor program decide the outcome.
