# SkyHedge Android visual system

The Android app follows the approved OpenDesign editorial-fintech prototype. This native-specific reference does not change the website's root `DESIGN.md`.

- Mode: operate. One job per screen and one primary action per decision point.
- Graphite canvas and restrained charcoal surfaces; warm-white primary text; slate secondary text. Mint marks a real selected action or verified state, violet is reserved for navigation identity, amber for pending research. No neon glow, decorative gradients, or repeated bordered cards.
- Space Grotesk is for short screen titles and place names; Inter is for controls, body, and data labels. Use an explicit type scale rather than many one-off sizes.
- Explore progresses from place to risk to evidence. After choosing a place, collapse the search/list into a concise location summary with a visible Change action.
- The reference map sits after the risk/evidence decision so geographic context does not interrupt the primary journey. It draws catalog reference points, never boundaries, synthetic station markers, or weather overlays. Exact text location remains visible when maps fail.
- Protect leads with contract terms, amount, readiness, and one action. Wallet and program diagnostics live in expandable details.
- Weather shows only source-dated NOAA observations. Wallet shows only real finalized balances and positions.
- Preserve Android safe areas, system Back, scalable fonts, screen-reader order, 48dp controls, and reduced-motion settings.
